# Chromatic Block Harmony

Download the problem package at contest.iimoc.org/package/blockharmony.

## Problem

You are given an array of $n$ integers $a[1], a[2], \ldots, a[n]$.

A **block** is a pair $(l, r)$ with $1 \leq l \leq r \leq n$ representing the contiguous subarray
$a[l], a[l+1], \ldots, a[r]$. The **sum** of a block $(l, r)$ is $a[l] + a[l+1] + \cdots + a[r]$.

You must select a (possibly empty) set of blocks and assign each block a **color** — an integer
in $[1, B]$. The selection must satisfy:

1. **Global non-overlap:** No two blocks (of any color) share an index.
   Formally, for all $i \neq j$, either $r_i < l_j$ or $r_j < l_i$.
2. **Color-sum consistency:** All blocks assigned the same color must have the same sum.
   Blocks of different colors may have different sums.

Your goal is to maximize the **objective**:

```
OBJ = alpha * k - beta * C
```

where $k$ is the total number of blocks selected and $C$ is the number of **distinct colors
actually used** (colors that appear on at least one block). If you select zero blocks, $\text{OBJ} = 0$.

This is an optimization problem: any feasible output is accepted and scored by its objective value.

---

## Input

```
n B alpha beta
a[1] a[2] ... a[n]
```

- $1 \leq n \leq 50000$: length of the array
- $1 \leq B \leq 20$: maximum number of colors you may use
- $1 \leq \alpha \leq 10^9$: reward per block
- $0 \leq \beta \leq 10^9$: penalty per distinct color used
- $0 \leq a[i] \leq 50$: array elements (non-negative integers)

---

## Output

```
k
l_1 r_1 c_1
l_2 r_2 c_2
...
l_k r_k c_k
```

- $k$: total number of blocks ($0 \leq k \leq n$).
- Each of the next $k$ lines gives the left index, right index, and color of one block.
- $1 \leq l_i \leq r_i \leq n$ and $1 \leq c_i \leq B$.

If $k = 0$, print only `0` with no further lines.

---

## Feasibility Requirements

Your output is **feasible** if and only if:

1. All indices satisfy $1 \leq l_i \leq r_i \leq n$.
2. All colors satisfy $1 \leq c_i \leq B$.
3. No two blocks overlap (global non-overlap condition above).
4. Within each color class, all blocks have the same sum.

An infeasible output receives a score of **0** on that test.

---

## Objective and Scoring

The checker computes and reports:

```
OBJ = alpha * k - beta * C
```

Higher $\text{OBJ}$ is better. $\text{OBJ}$ may be negative if $\beta$ is large and your solution uses colors
without enough compensating blocks; in that case outputting 0 blocks ($\text{OBJ} = 0$) would have
been better.

The judge aggregates per-test scores over all test cases; higher total is better.

---

## Example

### Input
```
26 1 6 2
3 46 36 20 0 24 35 34 37 5 8 14 12 37 35 47 17 49 24 40 17 24 31 26 20 2
```

### Output
```
3
6 6 1
19 19 1
22 22 1
```

### Explanation:

Only $B = 1$ color is available, so every selected block must share the same color and
therefore the same sum. The value $24$ appears at positions 6, 19, and 22. Selecting all
three single-element blocks gives $k = 3$, $C = 1$, and
$\text{OBJ} = 6 \times 3 - 2 \times 1 = 16$.

### Sample 2

#### Input
```
28 4 8 5
24 21 8 2 33 8 46 6 26 18 37 8 24 35 19 48 44 1 29 8 32 4 8 34 9 42 4 48
```

#### Output
```
11
3 3 1
6 6 1
12 12 1
20 20 1
23 23 1
22 22 2
27 27 2
1 1 3
13 13 3
16 16 4
28 28 4
```

#### Explanation:

With $B = 4$ colors available, we can group blocks by their element value:

- **Color 1** (sum = 8): positions 3, 6, 12, 20, 23 — five single-element blocks each
  containing the value 8.
- **Color 2** (sum = 4): positions 22 and 27 — both contain the value 4.
- **Color 3** (sum = 24): positions 1 and 13 — both contain the value 24.
- **Color 4** (sum = 48): positions 16 and 28 — both contain the value 48.

All 11 blocks are at distinct positions (no overlap). Within each color, every block has the
same sum. $k = 11$, $C = 4$, and $\text{OBJ} = 8 \times 11 - 5 \times 4 = 68$.

### Sample 3

#### Input
```
29 4 8 4
28 20 14 45 43 24 9 18 50 37 27 24 14 41 43 49 39 16 38 21 18 3 22 45 44 20 25 25 40
```

#### Output
```
9
5 5 1
15 15 1
21 23 1
3 3 2
13 13 2
2 2 3
26 26 3
6 6 4
12 12 4
```

#### Explanation:

With $B = 4$ colors and a per-color penalty of $\beta = 4$, it is worth spending a color only
if it covers enough blocks to recoup the cost. All blocks are non-overlapping and each color
group has a consistent sum:

- **Color 1** (sum = 43): positions 5 (value 43), 15 (value 43), and 21–23
  (18 + 3 + 22 = 43) — three blocks.
- **Color 2** (sum = 14): positions 3 and 13 — both contain the value 14.
- **Color 3** (sum = 20): positions 2 and 26 — both contain the value 20.
- **Color 4** (sum = 24): positions 6 and 12 — both contain the value 24.

$k = 9$, $C = 4$, and $\text{OBJ} = 8 \times 9 - 4 \times 4 = 56$.

## Test Generation

There are **30 judge test cases**. Each test is generated as follows:

- $n$ is drawn log-uniformly: $n = \lfloor 10^{U(1,\log_{10} 10000)} \rfloor$
- $B$ is drawn uniformly from $[1, 15]$
- $\alpha$ is drawn uniformly from $[1, 10^9]$
- $\beta$ is drawn uniformly from $[0, 5 \times 10^8]$
- Each $a[i]$ is drawn independently and uniformly from $[0, 50]$

---

## Constraints

- Time limit: 3 seconds
- Memory limit: 512 MB
